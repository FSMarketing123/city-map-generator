# City Map Generator

Line-art street maps of any US city, drawn from OpenStreetMap data, exported as SVG (vector) or high-res PNG.

**Use it:** https://fsmarketing123.github.io/city-map-generator/

1. Type a city, address or landmark and pick it from the suggestions.
2. Set the width in miles (about 5 for a downtown, 15–20 for a metro) and the shape.
3. Click **Generate map**, then adjust colors and line weights.
4. Export SVG for Illustrator or PNG for print.

Publishing a map? Credit "© OpenStreetMap contributors".

## Running it offline / locally

The map servers won't answer a page opened straight from disk, so on a Mac double-click
`Open City Map Generator.command`. It serves the page on this computer only and opens it in your browser.

Data: [OpenStreetMap](https://www.openstreetmap.org/copyright) via the Overpass API; place search by [Photon](https://photon.komoot.io).
